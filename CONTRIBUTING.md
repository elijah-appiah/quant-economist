# Contributing

This repository is primarily a personal, week-by-week learning log for a two-year self-directed program in econometrics, quantitative finance, DSGE modeling, machine learning, and deep learning. That said, contributions that improve accuracy or add value for others following a similar path are welcome.

## Ways to contribute

**🐛 Corrections**
If you spot a bug in code, an incorrect derivation, or a mathematical error, please open an issue with:
- The file and week number affected
- What's wrong
- (Optional) A suggested fix

**💡 Alternative implementations**
If you have a cleaner, faster, or more idiomatic R or Python implementation of a given week's task, pull requests are welcome. Please:
1. Keep the same file naming convention (`week-NN-topic-name.R` / `.py`)
2. Keep the implementation self-contained and runnable top to bottom
3. Briefly explain in the PR description what's different and why it's better

**📖 Documentation**
Typos, unclear explanations, or broken links in any `README.md` or notes file — PRs welcome.

## What I'd rather you not do

- Please don't submit solutions to weeks not yet reached — the point of this repo is a real, sequential learning record.
- Please don't restructure folders without discussion first (open an issue) — the structure mirrors the curriculum's week-by-week design intentionally.

## Code style

- **R**: tidyverse conventions where applicable, explicit `library()` calls at the top of each script
- **Python**: PEP 8, type hints where they aid readability, no notebook-only code without a `.py` equivalent when feasible

Thanks for reading this far — even if you never open a PR, if this structure helps your own study plan, feel free to fork it.
